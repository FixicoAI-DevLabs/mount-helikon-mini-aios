# Install Helikon Mini 4.0.0

Mini 4 is rebuilt from Helikon 6.0.0 for a dedicated ChatGPT project.

1. [Download the Mini 4.0.0 ZIP](https://github.com/FixicoAI-DevLabs/mount-helikon-mini-aios/releases/download/v4.0.0/Helikon-Mini-4.0.0.zip) and extract it. No Python or local build is required.
2. Create a dedicated ChatGPT project. Use project-only memory where available.
3. Copy the complete contents of `Helikon_Mini_System.md` into the project's Instructions. Save, reopen and compare the saved text with the file.
4. Upload `Helikon_Mini_Operating_Master.json` under project Sources. Wait for completion and confirm the content is readable.
5. Open a fresh chat in the project and try a normal task with a checkable answer. Mini should disclose missing or mismatched source access honestly. A filename or model assurance alone does not prove a complete read.

Always take both installation files from the same release. Your existing full Helikon project can continue running separately.
