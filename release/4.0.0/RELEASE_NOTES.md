# Helikon Mini 4.0.0

Mini 4 is the current Mini release, rebuilt from Helikon 6.0.0 for a dedicated ChatGPT project. It replaces 3.3 as the repository's default installation and GitHub Latest release.

## Install

Download and extract `Helikon-Mini-4.0.0.zip`. Put the complete `Helikon_Mini_System.md` into a dedicated project's Instructions and upload `Helikon_Mini_Operating_Master.json` as its source. Reopen the saved instructions and confirm the uploaded source is readable. Follow `START_HERE.md` in the ZIP. No local build or Saved Memory installation is required.

## What changed

- Current System and Operating files are at the repository root; the six original 3.3 files are archived unchanged.
- The Helikon 6-derived runtime replaces the old memory installation, approval-token parser and compulsory footer with scoped authorization, evidence checks, privacy, bounded repair and planning checks.
- Runtime identity is 4.0.0 and schema identity is 1.0.5. Operational rules match tested candidate 5; its historical evidence is preserved under its actual version.
- Installation guides, default downloads, build paths and release metadata now identify Mini 4.0.0.

## Validation and scope

All 38 automated tests pass, the Helikon 6 source inventory passes, and independent builds match byte-for-byte. Runtime/System/schema comparison confirms only identity changes from candidate 5. The ZIP checksum is supplied separately.

Candidate 5's browser/Pro/GPT-5.6 Sol Medium project tests recorded 48 core case-runs, five supplementary probes, 24 utility runs and three additional planning probes. A fresh 4.0.0 ChatGPT installation was not run because the browser service was unavailable. Historical observations are not relabelled as fresh tests.

Complete hidden source delivery every turn, global chats, free accounts, other models and general utility gains remain unverified. Profile assurance stays `experimental_unverified`, and the strict source-evidence gate is unchanged. The current-release designation does not certify broader support.
