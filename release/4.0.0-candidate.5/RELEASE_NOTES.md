# Helikon Mini 4 — Project beta (candidate 5)

Release scope: experimental installation in a dedicated ChatGPT project. Runtime version: `4.0.0-candidate.5`. This distributes the exact candidate-5 package tested in the repository; it is not a stable global-chat release.

## What changed from Mini 3.3

Mini was rebuilt from the released Helikon 6.0.0 master. The new edition uses short project instructions and one compact Operating JSON, with explicit source identity, schema checks, deterministic packaging and documented recovery. It retains three planes and twelve responsibilities without requiring six Saved Memories, mandatory approval tokens or compulsory response footers. Candidate testing led to repairs for task/configuration confusion and invented planning work.

## Install or move from Mini 3.3

Download `Helikon-Mini-4.0.0-candidate.5.zip` from this release's assets and extract it. Open its `START_HERE.md`, put the matching System text in a new project's Instructions, and upload its Operating Master JSON to Sources. No local build is required. Do not substitute GitHub's automatically generated source-code archive for the install package.

Existing account settings do not update automatically. Preserve the old configuration and evaluate Mini 4 in a separate project before retiring Mini 3.3. Actual six-Saved-Memory migration remains untested. Avoid bulk deletion and preserve unrelated preferences and full Helikon installations.

## Evidence and limits

Testing used browser ChatGPT on Pro with GPT-5.6 Sol / Medium. Candidate 5 passed 48 core case-run criteria, five supplementary probes, 24 utility runs and three additional planning probes. Thirty-eight automated tests and reproducible packaging checks pass. Exact saved System text was verified, and bounded source copies reconstructed the complete runtime.

Hidden complete-runtime delivery on every turn is not observable and the strict source-evidence gate remains unmet. A one-response full-file-copy request still failed; optional extra prose and configuration citations remain. Ordinary global-chat delivery, free accounts, other models and actual legacy-memory migration are untested. The earlier comparison does not establish general benefit over a concise baseline. These results support limited project evaluation, not broad reliability or production-support claims.

Read the [candidate-5 evidence](https://github.com/FixicoAI-DevLabs/mount-helikon-mini-aios/tree/v4.0.0-candidate.5/release/4.0.0-candidate.5/browser-pilot-05), [start guide](https://github.com/FixicoAI-DevLabs/mount-helikon-mini-aios/blob/v4.0.0-candidate.5/START_HERE.md) and [migration procedure](https://github.com/FixicoAI-DevLabs/mount-helikon-mini-aios/blob/v4.0.0-candidate.5/docs/migration.md). Mini 3.3 remains available under its original tag; this prerelease does not replace GitHub's latest-stable label.
