Full-body per-turn fields in the strict evidence gate have not been fabricated or marked complete.

The installation journal records exact System readback, completed source upload, preserved fictional existing instructions, synthetic legacy replacement, cancelled edits, duplicate-request inspection, rollback and fresh-chat behavior. A real Save-then-immediate-reload probe left acknowledgement unobserved; reopening showed the write absent. ## Evidence fidelity

Most records contain DOM conversation snapshots and copied response Markdown. Four records (`B07-1`, `B11-1`, `B13-1`, `B15-2`) were restored as labelled content transcriptions from previously observed tool output after capture-file loss. They are not byte-identical clipboard captures. Other recoveries reopened existing conversations; they were not silent reruns. Explicit file sync and a complete in-memory checkpoint recovered later captures. Timestamps retain their observed values. Optional configuration citations and extra follow-up offers still occurred in ordinary prose despite the intended silent-application rule.

This report records bounded external observations and manual review. It neither certifies hidden instruction delivery nor authorizes release.
