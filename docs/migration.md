# What changes from Mini 3.3

The account-wide setup is preserved: two Personalization snippets and a guided installer for ordinary chats, with optional Projects. The Operating Layer changes from six Saved Memories to one Helikon 6-derived JSON saved in Library.

This release does not require a legacy memory migration and does not delete old memories. **REMEMBER** now explains the JSON route. Use **SETUP** from the current unified install package, preserve existing settings and complete fresh ordinary-chat verification.

Full Helikon 6 already running on an account is not a Mini migration target. Keep that working configuration intact while reviewing this starter. The prior 4.0 project-only package remains historical and is not evidence that 4.1 account-wide delivery works.
