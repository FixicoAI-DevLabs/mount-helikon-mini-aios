# Support and evidence boundaries

| Surface | Role | Current evidence |
|---|---|---|
| Account Personalization + Library JSON in ordinary chats | Primary Mini installation | Implementation complete; live save/readback and automatic fresh-chat source access unverified |
| Manual Add from Library in an ordinary chat | Explicit fallback | Must be observed separately; cannot pass automatic-access acceptance |
| Chat session with an attached runtime | Optional bounded session delivery | Experimental; prior evidence is version- and surface-specific |
| ChatGPT Project | Optional workspace and alternate explicit source delivery | Historical candidate tests exist; they do not establish the new System contract |
| Work mode | Separate host surface | Full Helikon's recorded Work test is not a Mini ordinary-chat test |
| Free account | Design target for the free starter | Both Mini snippets fit 1,500 characters; full live Free-account validation remains unrun |

The repository deliberately keeps all profile support values `experimental_unverified`. Static CI checks file consistency, schema, behavior anchors, installer boundaries, evidence records and reproducible packaging. It does not interact with ChatGPT or prove model obedience.

The published 4.0 release is the earlier project edition. The 4.1 installer corrects the product model but is not promoted as a verified account-wide release while required live checks are missing.

## Host features

OpenAI documents Custom Instructions applying across chats and Library storage/search/attachment features. Available tools, search controls, account policies and actual source reads still need observation. The installer must disclose missing access rather than claim activation.

## Historical observations

Candidate 5 project tests and earlier utility comparisons remain in `release/` with their original scope. No old transcript has been relabelled as an ordinary-chat test, and no artifact check is presented as a host installation test.
