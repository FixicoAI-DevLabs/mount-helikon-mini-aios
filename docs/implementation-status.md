## Evidence and limits

See the versioned engineering receipt under `release/4.0.0-candidate.1/` and the reproducible commands in `validation.md`. Unit-test fixtures are synthetic validator tests, not successful model transcripts. An evidence validator can establish internal record consistency and file integrity; it cannot authenticate an asserted host session or authorize release.

The evidence template remains explicitly `not_run`; validating it returns an unmet-evidence result rather than a success. Actual behavior needs 48 primary observations, supplementary format/source cases and seven installation transitions. Utility needs 72 comparisons plus substantive benefit/cost review. All failures and reruns must remain visible.
